<b>Knight Quest</b> is a mod that adds over 30 armor sets, each with passive abilities, hostile mobs with unique skills, new weapons, tameable mobs, a boss with 3 phases, and much more. The mod revolves around a block called the <i>Great Chalice</i>, which must be filled with Great Essence (crafted by combining 4 Small Essences obtained from killing monsters). Once the Chalice is completely full, you can use an empty goblet to fill it and use it as a crafting item or to summon the boss.

## Developer info
If you’d like to develop an addon for the <b>Knight Quest</b> series, you can either expand the content of this mod or download <a href="https://github.com/Xylonity/Knight-Lib" rel="nofollow">Knight Lib</a> directly and create something entirely new. For the latter, if you need to add specific functionality to the <i>Great Chalice</i> for gameplay purposes, simply add your custom functionality by mixing it into the <i>useItem</i> method the chalice implements (without overriding the existing content).
